## Heights, averaging and Alfvén speed

Cube `Model` metadata selects the matching HDF5 snapshot. All seven snapshot times exactly match a cube frame. The unitless legacy profile z coordinate was checked numerically against the cube’s centimetre-valued xc3 centres and xb3 cell boundaries. Maximum centre discrepancies are only about 5.82 cm from stored numerical precision. Heights use the existing origin `xc3[0]`; this is a coordinate convention, not a new determination of optical-depth unity. Dataset height indices and resolved physical coordinates are cross-checked. Historical HTML exports use saved navigation height metadata, verified against the original cube coordinate.

An additional 139 selectable legacy FITS products lack saved height metadata. Only those products use the permitted canonical-filename fallback. Each height pair must identify exactly one native layer pair; both the historical native-height convention and current relative-height convention are checked. Ambiguous or unmatched pairs fail explicitly. The resulting sidecars record this fallback and the coordinate convention actually matched. This resolves older names such as `hx_10g_bb3_1589_92km_2249_92km_komega.fits` to the exact current 0–660 km interval without changing the FITS data or its identity.

Scalar sampled profiles use piecewise-linear interpolation at exact interval endpoints and trapezoidal integration over actual nonuniform heights, divided by absolute separation. Reversed ordering gives the same atmospheric averages. Zero separation returns the interpolated point value and Δz = 0. No extrapolation, skipped invalid cells, or arithmetic bin averaging is used. Invalid scalar samples cannot cancel into a seemingly valid average. Inconsistent diagram/cube heights block atmospheric launches; missing inputs retain explicit fallback provenance. Missing density does not discard independently valid thermal inputs.

Magnetic components are horizontally averaged from the **same exact snapshot** as the thermal file. The cube’s already horizontally averaged rho is read at that frame. Declared G and g/cm³ are converted to tesla and kg/m³. Then `|B(z)| / sqrt(mu0 rho(z))` is evaluated before averaging, with `mu0 = 4π × 10⁻⁷`. Adaptive quadrature integrates this nonlinear function of the piecewise-linear component/density profiles, splitting at native grid knots and inserting exact boundaries. It does not calculate Alfvén speed from separately height-averaged B and rho. Results enter the models in km/s.

The previous cgs formula `B/sqrt(4π rho)` was algebraically correct. The superseded theoretical-default aggregation used endpoint means or a reference atmosphere plus separately averaged quantities; the new default path uses the matched snapshot and height integral. Existing legacy magnetic diagnostic statistics remain preserved and identifiable.

H is derived as `-1/(d ln rho/dz)` on the actual nonuniform cube coordinate before averaging. Magnetic direction is the direction of the height-integrated unit vector, avoiding direct averaging of wrapped angles. θ is inclination from +z and φ is atan2(By,Bx) from +x toward +y; the existing adapter converts degrees to radians and rebuilds Alfvén components. Zero field uses documented solver-neutral angles. The scalar N/cₛ/cutoff inputs themselves are averaged; this is not a claim that squared model coefficients or nonlinear solutions commute with averaging.

## Physical approximations

The atmospheric snapshot represents a longer simulation time series. Its thermal profiles are horizontal means; magnetic/density profiles are independently averaged and already vertically binned to six levels in these cubes. Their nonlinear Alfvén speed is not the horizontal mean of the original local Alfvén speed. Interpolation cannot restore unresolved vertical structure. Magnetic direction and mean magnitude describe a representative mean field, without replacing unresolved/turbulent magnetic statistics. Scale heights derived from six levels are correspondingly coarse.

The original homogeneous/locally uniform dispersion relations retain their assumptions, including their own magnetic geometry and radiative closure. Height-averaged inputs do not make them exact solutions of the vertically stratified problem. The isothermal acoustic-cutoff definition is retained for NC2009; the non-isothermal profile is separately shown in the diagnostic. The adiabatic-index interpretation, missing relaxation time and unsupplied gravity remain explicitly documented limits. Near-horizontal mean fields and zero-field cases can expose existing native root degeneracies; the existing solver warnings and independent curve controls are retained, and physical inputs are not clamped to conceal these conditions.
