The shared Bokeh implementation has been repaired and the loopback service at port 5013 restarted with the changes. Existing megaplot HTML launches this service; its embedded launch records and scientific image products did not require regeneration or individual patches.

Workers run only the existing numerical solver and never read Bokeh widgets or mutate the document. Sampling and physical input changes invalidate obsolete results. Height-separation/reference-only edits, including edits during a pending solve, use the native postprocessor and reuse the exact roots. Native branch tracking, model caches, all seven models, shared parameter synchronization, coherence weighting, and atmospheric initialization are retained. The legacy explorer still maintains its existing cached-tab data contract.

The dispersion solver and its equations were not changed. The two full-grid timings are single runs; their difference is not evidence of a solver optimization. The improvement is that solving no longer occupies the UI event loop. Browser preview rendering is scheduled on the next animation frame without the Python debounce or round trip; no universal end-to-end frame-rate claim is made.
